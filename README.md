# Traffic Accident Analysis

## Objective
Analyze traffic accident data to identify patterns related to road conditions, weather, and time of day. Visualize accident hotspots and contributing factors.

## Dataset
Indian Traffic Accident Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Folium

## Analysis Performed
- Data Cleaning
- Exploratory Data Analysis
- Weather Impact Analysis
- Road Condition Analysis
- Time-of-Day Analysis
- Accident Hotspot Visualization
- Contributing Factors Analysis

## Results
- Identified peak accident hours.
- Studied impact of weather conditions.
- Analyzed road conditions causing accidents.
- Generated accident hotspot heatmap.
